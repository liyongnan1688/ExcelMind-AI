一、 插件定位与特点
------------------------------------------------------------------------
Lee-Excel 是专为 Windows 平台 Microsoft Excel 设计的桌面级原生 AI 插件。
- 深度兼容：支持 Office 2010 / 2013 / 2016 / 2019 / 2021 及 Microsoft 365；
- 双架构适配：内建 32 位与 64 位自适应引擎，完美支持各类新老电脑；
- 沉浸式侧边栏：采用 Office Fluent 原生视觉风格与微软 Edge WebView2 内核；
- 数据安全保障：多工作簿目标锁定、自动快照保护与防篡改验证。

二、 快速使用方式（两种任选一种）
------------------------------------------------------------------------
【方式一：一键安装（永久常驻推荐）】
1. 双击运行【安装插件(开启常驻).bat】；
2. 脚本将自动解除系统下载锁定、检测系统运行库，并将插件注册到 Excel 启动项；
3. 打开任意 Excel 文件，顶部功能区将自动出现【AI 助手】专属选项卡！

【方式二：免安装便携运行（临时演示/即开即用）】
1. 双击运行【免安装启动.bat】；
2. 脚本会自动侦测当前电脑 Excel 的位数（32位或64位），直接唤醒 Excel 并挂载插件；
3. 不对注册表做任何修改，绿色干净。

三、 卸载与清理
------------------------------------------------------------------------
若需注销插件：
1. 双击运行【卸载插件.bat】；
2. 脚本将安全移除 Excel 启动项并保持其他原有插件不受影响。

四、 运行环境要求与常见排错
------------------------------------------------------------------------
1. 系统支持：Windows 7 SP1 / Windows 10 / Windows 11 (32位与64位均支持)；
2. .NET Framework：需要 .NET Framework 4.6.2 或更高版本（Win10/11 均已内置）；
3. WebView2 运行时：
   - Windows 11 及较新的 Windows 10 系统已默认内置；
   - 若在老系统或精简版系统中运行时提示“未检测到 WebView2 运行时”，在运行安装脚本时
     按回车即可自动从微软官方极速下载安装（约2MB）；
   - 离线内网电脑可提前从微软官网下载 Microsoft Edge WebView2 独立安装包：
     https://developer.microsoft.com/microsoft-edge/webview2/
4. Office 信任中心提示：
   - 本安装脚本已在第一步自动解除了从微信/网盘下载附带的“锁定属性”；
   - 若 Excel 选项提示宏被阻止，请进入 Excel【文件】->【选项】->【信任中心】->【信任中心设置】->【宏设置】，选择“启用所有宏”或“禁用所有宏并发出通知”。
