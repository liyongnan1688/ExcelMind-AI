# ExcelMind AI 用户操作使用手册 (USER_GUIDE.md)

> **版本**：v1.3.0-rc1  
> **当前状态入口**：参见 [docs/CURRENT_STATE.md](CURRENT_STATE.md)  
> **适用对象**：表格分析师、业务专员、自动化开发者及日常 Excel 用户  
> **宿主架构**：Windows 桌面 Excel + C# COM Interop + WebView2 (Svelte 5)

---

## 1. 首次配置与大模型服务接入

### 1.1 大模型配置入口
启动 Excel 并打开右侧【ExcelMind AI】面板后，点击面板右上角的 **⚙️ 设置** 图标，进入【模型设置】标签页：
- **API 提供商 (Provider)**：支持 OpenAI 兼容接口（如 DeepSeek、Kimi、通义千问、MiniMax、Claude 等各类标准 OpenAI 兼容服务）；
- **API Base URL**：填写模型服务提供商的接口地址（例如 `https://api.deepseek.com/v1` 或自建网关地址）；
- **API Key**：填写您的专属 API 访问密钥；
- **模型名称 (Model)**：指定需要调用的模型代号（例如 `deepseek-chat`、`gpt-4o` 等）；
- **Temperature / 采样温度**：推荐保持 `0.1` ~ `0.3`，以确保生成的 VBA 代码具备高确定性与代码保真度。

### 1.2 计费与网络流量消耗严正提示
> [!WARNING]
> **API 计费风险警示**：
> - 大模型服务接入直接使用您所配置的服务商账户。每次向助手提问、分析选区或生成代码，都会**消耗您在对应服务商的 Token 额度并产生实际计费**。
> - 在处理包含大篇幅单元格的选区附加时，建议留意上下文卡片中预估的 Token 数量；
> - **强烈建议**：初次使用或测试新功能时，请先在空白或小型测试工作簿上进行小范围试用，确认计费与消耗符合预期后再逐步应用于日常生产工作。

## 2. 核心功能操作与预期效果

### 2.1 自然语言转 VBA 忠实执行
- **操作方式**：
  在底部输入框输入中文自然语言需求（例如：“将当前工作表 A 列到 F 列斑马线交替上色，首行表头深蓝底白字加粗”），模式选择【自动化 (AUTOMATION)】并发送；
- **保真执行原则**：
  宿主对大模型生成的 VBA 源码**100% 原样保真注入执行**，绝不进行隐蔽的引号替换、变量篡改或删除 `Option Explicit`；
- **过程透明与写后读回**：
  宏执行完成后，卡片默认以一句话简洁汇报；展开后可查看完整的原始生成代码、实际注入模块名、执行耗时以及受影响区域的写后读回验证（Readback）数据。

### 2.2 自动快照与安全回滚边界
- **物理自动备份机制**：
  每次通过自动化模式执行宏代码之前，宿主会自动在 `%APPDATA%\ExcelMindAI\Backups\` 下为当前活动工作簿创建物理副本快照（`.xlsx` / `.xlsm`）；
- **一键恢复**：
  若执行结果不符合预期，点击执行卡片右上角或底部的 **“一键回滚” (Rollback)** 按钮，即可将工作簿立刻恢复到本次操作前的精准状态；
- **回滚边界说明**：
  > [!NOTE]
  > 快照仅保障**当前目标工作簿本身的表格内容与工作表结构回滚**。无法撤销宏代码内调用的外部系统级操作（例如宏内部自行执行的文件删除、HTTP 发送或外部数据库修改）。

### 2.3 选区感知与只读附加 (R1)
- 在表格中框选任意数据区域，输入框上方将自动展示【附加选区】浮动胶囊；
- 点击附加后，可展开查看只读抽样数据卡片（展示表头、前几行抽样及预估 Token 占用）；
- 选区附加过程完全只读，绝不写表。

### 2.4 宏库管理与免 API 免联网复用 (R2)
- **保存宏入库**：对于生成成功的高频自动化任务，在卡片上点击 **“保存至宏库”**，即可命名、添加标签并存入本地宏库；
- **免 API 永久复用**：已保存的宏脚本直接由本地 C# 宿主调度执行，**完全免 API Key、零网络请求、零费用消耗**；
- **常用宏动态菜单**：支持在宏库侧边抽屉中一键置顶收藏，Excel 顶部功能区动态渲染【常用宏】下拉菜单，支持一键点击直接运行；
- **参数化宏契约**：对于含有可调节参数的脚本（如筛选阈值、日期范围），支持定义参数表单，运行时弹出直观输入框。

### 2.5 快速数据清洗与两表对账工具 (R3)
- **按键去重工具**：
  点击顶部【数据工具】->【按键去重】，选择主键列与多列组合键，采用纯本地高速哈希算法去重，支持保留首条、末条或直接删除重复，并给出清晰统计报告；
- **两表主键对账工具**：
  点击【数据工具】->【两表对账】，支持工号、订单号等关键字段的**前导零与长文本严格保真**，在独立工作表生成差异对比分析报告，绝不篡改或覆盖用户原始表格。

### 2.6 批量文件任务引擎 (R4)
- **批量运行宏**：
  点击顶部【批量处理】，选择一个本地文件夹内的多个 Excel 工作簿（`.xlsx` / `.xls` / `.xlsm`），勾选宏库中的既有脚本；
- **副本试运行与隔离输出**：
  支持“副本安全试运行”模式，处理后的文件统一保存在独立的 `_output` 目录中，支持任务中途安全暂停与取消。

### 2.7 可复用工作流与原生图表生成 (R5)
- **工作流串联流水线**：
  在【工作流】面板中，可将“数据去重 -> 格式规整 -> 汇总生成”多步骤串联成固定流程，支持单步调试、全流程任务级快照与一键连续重放；
- **原生 Excel 图表生成**：
  支持自由生成或模板式生成柱状图、折线图、饼图、面积图等标准 Excel 嵌入式图表，由 COM 直接调用 Excel 原生图表引擎，完全保留 Office 矢量美观度。

### 2.8 只读外部数据接入与宏包导入导出 (R6)
- **外部数据接入 (R6a)**：
  支持读取本地 CSV、本地 JSON 文件或受信任的内部 HTTP GET 接口数据，严格实施只读模式与 URL 白名单防护；
- **无凭据宏包导入导出 (R6b)**：
  支持将本地沉淀的自编宏打包为 `.zip` 格式的共享宏包，包内严格剔除个人凭据与业务数据，支持在同事或团队成员间无损导入分发。

## 3. 数据安全与隐私防线

1. **凭据安全存储与保护机制**：
   - **大模型 API Key**：保存在本地内置 WebView2 的 `LocalStorage` 中，仅用于本地直接向用户配置的模型提供商接口发起请求，插件绝不上报或中转第三方云端；该路径**未采用 Windows DPAPI 保护**；
   - **外部数据源连接凭据**：在启用受保护外部数据源时，独立采用 Windows 数据保护 API (DPAPI) 的当前用户范围保护 (`DataProtectionScope.CurrentUser`) 本地加密存储在 `%APPDATA%\ExcelMindAI\` 中；二者机制不同，不能将 DPAPI 保护外推到模型 Key。
2. **零云端遥测与纯本地运行**：
   - 插件自身不包含任何第三方追踪、统计分析或云端日志上传组件；
   - 外部网络访问仅限于用户自主配置的大模型接口。
3. **脱敏诊断包导出规范 (R6c)**：
   - 点击设置中的【系统诊断】选项卡，支持一键脱敏导出 `ExcelMindAI_Diagnostics_<timestamp>.zip`；
   - **绝对排除清单 (8 类)**：凭据/API Key、HTTP 授权头、会话历史与 Prompts、宏库源码、参数明细、工作簿单元格业务数据、快照文件、外部接口响应数据；
   - 诊断包导出为纯本地保存，支持用户自行选择存储路径或取消，不自动联网发送。

## 4. 使用限制与已知边界

1. **宏信任中心与企业组织安全策略**：
   - 插件自动化任务需调用 Excel VBA 工程对象模型接口；
   - **企业限制环境说明**：若企业或组织通过域控组策略（GPO）强制禁用了宏或禁用了对 VBA 工程对象模型的访问，自动化执行功能在受限环境中**明确不可用**。本插件完全尊重并遵守组织安全规范，**绝不提供亦不引导用户绕过、破解或违规修改组织安全策略**；
   - 在个人设备或受允许的环境中，可在 Excel【文件】->【选项】->【信任中心】->【信任中心设置】->【宏设置】中按需配置；
2. **快照回滚能力边界**：
   - 每次执行自动化宏前，宿主会对目标工作簿创建物理备份副本，支持一键无损恢复当前工作簿；
   - **快照不是任意 VBA 的安全沙箱**：快照仅恢复目标工作簿本身的表格内容与工作表结构，无法撤销宏代码内调用的外部系统级操作（例如宏内部自行执行的独立文件删除、HTTP 发送或外部数据库修改）；
3. **架构与真实 API 验证边界**：
   - 安装包内已内置 32 位（`LeeExcel.xll`）与 64 位（`LeeExcel64.xll`）双架构加载项；
   - 自动化验收套件已在 Windows 11 64 位 + 64 位 Excel 桌面宿主上完成验证；
   - 32 位 Office 宿主运行环境及真实商业大模型 API 线上调用目前处于“运行未验证”状态；
4. **功能区 (Ribbon) 当前布局**：
   - 顶部选项卡为【ExcelMind AI】；
   - 第一分组名为【ExcelMind AI】，展示 32×32 品牌大图标，下方无按钮文字，悬停提示为“打开或收起 ExcelMind AI 工作台”；
   - 常用宏、数据工具、批量处理与设置分别收敛至【宏与数据】和【任务与设置】分组中；
5. **长耗时宏与界面响应**：
   由于 Excel COM 是单线程单套间（STA）执行模型，在处理超大规模数据（例如数十万行密集运算）时，Excel 界面可能会短暂呈现“计算中”状态，建议此类场景采用批量分块或提前备份；
6. **宿主范围限定**：
   当前版本专为本地 Windows 桌面版 Microsoft Excel（2010 及以上）深度优化设计，暂不支持网页版 Office Online、macOS 或移动端。
