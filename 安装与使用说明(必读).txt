================================================================================
                    ExcelMind AI 安装与快速上手指南
================================================================================

感谢使用 ExcelMind AI！本插件是专为 Microsoft Excel 打造的智能 AI 助手与自动化工具。
支持 Office 2010 / 2013 / 2016 / 2019 / 2021 及 Microsoft 365（支持 32 位与 64 位）。

--------------------------------------------------------------------------------
【第一步：解压文件】
--------------------------------------------------------------------------------
1. 请勿直接在压缩包内双击运行脚本！
2. 请将本压缩包完整解压到您希望存放插件的固定目录。
   推荐路径示例：
   - D:\Tools\ExcelMindAI\
   - C:\Users\<您的用户名>\ExcelMindAI\
   （注意：请不要放在临时文件夹、回收站或可能会被清理的“下载”文件夹中）

--------------------------------------------------------------------------------
【第二步：选择安装方式】
--------------------------------------------------------------------------------
★ 推荐方式（一键常驻安装）：
   1. 请先完全退出当前电脑上所有正在运行的 Microsoft Excel；
   2. 双击运行当前目录下的【安装插件(开启常驻).bat】；
   3. 脚本会自动检测您的 Excel 架构（32位/64位）并完成自启动配置（无需管理员权限）；
   4. 启动 Excel，顶部功能区会自动出现【ExcelMind AI】专属标签页与侧边智能工作台！

★ 便携方式（免安装绿色试用）：
   1. 请先完全退出 Excel；
   2. 双击运行当前目录下的【免安装启动.bat】；
   3. 自动调起 Excel 并加载插件，不修改系统注册表自启动项，退出 Excel 即自动卸载。

★ 卸载方法：
   1. 完全退出 Excel；
   2. 双击运行当前目录下的【卸载插件.bat】即可干净注销所有注册表项。

--------------------------------------------------------------------------------
【第三步：首次使用配置与注意事项】
--------------------------------------------------------------------------------
1. Windows 安全提示（SmartScreen 拦截）：
   由于这是社区未签名构建版，首次运行时 Windows 可能弹出“Windows 已保护你的电脑”：
   -> 请点击界面上的【更多信息】
   -> 点击【仍要运行】即可正常启动。

2. Excel 宏与 VBA 信任设置（重要）：
   为了让 AI 能够自动化帮您操作工作表，需开启 VBA 信任：
   -> 打开 Excel，点击左上角【文件】->【选项】->【信任中心】->【信任中心设置】；
   -> 点击左侧【宏设置】；
   -> 勾选【信任对 VBA 工程对象模型的访问】并确定。

3. 模型配置（API Key）：
   -> 在 Excel 侧边栏的 ExcelMind AI 面板中，点击右上角【设置】齿轮图标；
   -> 填入您的大模型 API 地址与 Key（支持 OpenAI、DeepSeek、Moonshot/Kimi、通义千问等兼容接口）；
   -> 保存后即可开始对话或下达数据处理自动化指令！

4. 工作簿保存与快照安全门禁（重要）：
   -> 为确保数据资产绝对安全，每次运行宏前插件会自动为当前工作簿创建整本物理副本快照；
   -> 若为刚新建且尚未保存到磁盘的表格（如“工作簿1”、“工作簿2”），系统会安全阻断执行，【立即执行】按钮置灰；
   -> 解决办法：在 Excel 中按快捷键【Ctrl + S】将工作簿先保存到电脑任意路径，按钮将自动解锁点亮！

--------------------------------------------------------------------------------
